
# P4 - Evaluation

This folder contains code to evaluate our baseball pitch prediction model.

## Files
- `evaluate.py` - Calculates accuracy, log loss, and a confusion matrix.
- `sample_predictions.csv` - Sample data used to test the evaluation code.

## How to Run
python evaluate.py sample_predictions.csv

## Next Steps
